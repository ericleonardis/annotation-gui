# annotation-gui
Annotation GUI for labeling multiple videos for behavioral segmentation. 

Define a behavioral lexicon and segment the video into different behaviors. Interactively change the start and end point of the behavior and export the timepoints and frame numbers to csv for multiple videos.

Tested on Mac M1.
